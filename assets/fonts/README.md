# WeaveFall reusable font files

These WOFF2 files are unchanged binary copies extracted from the author's existing public Home-Font.css. The original font-family names, styles and weights are retained in Home-Font.css. Font provenance is recorded in ../font-assets.json; copying these files does not create a new licence or change upstream font terms.

The campaign loads Kaiburr directly from its pinned GitHub WOFF2 URL. For another Homebrewery document, paste the desired @font-face rule from Home-Font.css and use its raw GitHub font URL. Alternatively, import Home-Font.css through a GitHub CSS CDN such as jsDelivr, using the published commit, since raw GitHub CSS is served as text/plain. No data: URLs are needed.
