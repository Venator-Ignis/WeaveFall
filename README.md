# WeaveFall Campaign Artwork

Image library for the WeaveFall A4 Homebrewery campaign book. The library includes selected book illustrations, character and creature reference sheets, layered maps, player handouts and high-resolution PNG exports.

- `assets/book`: stable image paths used by the campaign manuscript.
- `assets/references`: architecture, uniform, character and creature model sheets.
- `assets/maps`: editable versioned SVG map and handout masters.
- `assets/maps/png`: PNG map/prop exports, including GM, player, blank and exploration-detail versions.
- `assets/masks`: unchanged Homebrewery watercolour masks used by the book's CSS.
- `assets/fonts`: reusable WOFF2 files, original font-family declarations and provenance.

Files, roles and hashes are listed in `asset-manifest.json` and `IMAGE_INDEX.csv`. Production credits are in `CREDITS.md`. Use player copies with the group; GM maps include planning and encounter annotations. Regional absolute coordinates are proposed cartography; fixed preparation and movable discovery pins are distinguished.

The book image base URL is:

```text
https://raw.githubusercontent.com/Venator-Ignis/WeaveFall/main
```

The dedication photograph is author-supplied and published with the author's authorization. Generated artwork remains credited as generated; the ink revision reduces polished lighting and surfaces.

The reusable font stylesheet is [Home-Font.css](assets/fonts/Home-Font.css). Paste the selected @font-face rule with a direct raw GitHub WOFF2 URL, or import the stylesheet through jsDelivr. Font provenance is in [assets/fonts/README.md](assets/fonts/README.md).

The current cover is a composition proof awaiting its final print-resolution master. Original image masters and the campaign's editable manuscript are maintained in the author's local project.
